# HIL Benchmark Protocol v1.0
1. Freeze model, harness, ladder id, resources, authority, task version and intervention policy.
2. The experimental unit is A(m,h), not the model alone.
3. If two rungs do not change the executor request, reuse the same executor artifact for paired scoring.
4. Independent verifier/hidden tasks/acceptance thresholds remain outside candidate write access.
5. Log H0-H5, CID0-CID6, human cognitive minutes and governance approvals separately.
6. I1+ requires real restart/context discontinuity; I2+ requires later behavior changed by stored experience.
7. I3+/O3+ require external promotion evidence across multiple changes; I4+ requires improvement-of-improvement evidence.
8. T5+/I5+/O5+/U5+ require hidden novelty mechanisms and reproducibility checks.
9. Publish per-instance failures, confidence intervals, resource envelopes and saturation diagnostics.
10. HSC is primary; HIL summaries must not hide the curve.
