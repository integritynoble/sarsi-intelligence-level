# C-Bench
Measures Cognitive Intelligence C0-CΩ under minimal standardized harness conditions.
Families include logic, math, science, causal reasoning, coding, abstract induction, factuality/calibration,
long context, structured multimodal reasoning, and GUI Perception (GP).
GP is inside C, not a separate top-level intelligence coordinate.
The `gui_assets/` directory contains image-backed synthetic UI items with element/state/bounding-box keys.
