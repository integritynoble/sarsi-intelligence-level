# I-Bench v1.1
Measures Individual Intelligence independently from Memory Capability.

I-Bench scores I-specific functions: continuity, adaptive learning, governed self-improvement,
recursive improvement, autonomous discovery, and open-ended individual evolution.

Memory is supplied as a separate prerequisite gate from M-Bench:
I0>=M0; I1>=M1; I2>=M3; I3>=M4; I4>=M4; I5>=M5; IΩ>=M5,
with MΩ required only if evolution of the memory architecture itself is part of the IΩ claim.

A high M score cannot automatically raise I.
