# M-Bench v1.1
Measures independent supporting Memory Capability M0-MΩ.

M is not a sixth conceptual intelligence family and is not included in the default HLIS product.
It is nevertheless benchmarked independently because memory capability can exceed Individual Intelligence.

Formal relationship:
I(A) >= I_n  =>  M(A) >= mu_n
The converse does not hold.

M0 ephemeral; M1 persistent; M2 structured episodic; M3 consolidating;
M4 self-managing; M5 longitudinal knowledge system; MΩ externally evaluated memory-architecture evolution.
