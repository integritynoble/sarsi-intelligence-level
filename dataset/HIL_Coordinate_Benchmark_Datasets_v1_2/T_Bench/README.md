# T-Bench
Calibrates Task Difficulty T0-TΩ. T is a property of tasks, not an agent intelligence score.
Every task carries a 9-component vector:
L horizon, K dependencies, U uncertainty, A ambiguity, X tool diversity, V verification burden,
N novelty, E environmental change, and P_vis visual/interface complexity.
Use T together with H and reliability p to measure Delegation Intelligence.
