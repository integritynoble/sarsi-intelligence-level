# HIL Coordinate Benchmark Protocol v1.1

## Core vs supporting coordinates
The core measured profile is [C,I,O,T,H,SA]. DI is derived from T×H×p.
Memory Capability M is an independently measured supporting coordinate.

M is not a sixth conceptual intelligence family and is excluded from the default HLIS product.
The one-way dependency is:
I(A) >= I_n => M(A) >= mu_n
The converse is false.

## C
Use minimal standardized harness conditions. C measures problem solving, not persistence.
GUI Perception GP is a diagnostic subscale inside C.

## M
M1+ persistence must survive genuine process/context discontinuity.
M2 tests structured episodic memory: relevance, provenance, temporal order, current-vs-obsolete state.
M3 tests consolidation/proceduralization, updates, contradiction handling, forgetting/demotion.
M4 tests memory management/repair/utility/snapshot behavior.
M5 tests long-horizon hypothesis/evidence/decision lineage.
MΩ requires memory-mechanism changes evaluated by frozen hidden tests with rollback and lower-M retention.

## I
Score I-specific behavior separately from M.
I1 continuity, I2 adaptive learning, I3 governed cognitive self-improvement, I4 recursive improvement,
I5 autonomous discovery, IΩ open-ended individual evolution.
A run can certify I_n only when the I suite passes AND M>=mu_n.

## O
Use real separate roles/processes with evidence-bearing communication.
O3+ requires protected evaluator/promoter separation.

## T
T is a task property. Publish (L,K,U,A,X,V,N,E,P_vis).

## H
Log H0-H5, CID0-CID6, intervention count, cognitive minutes, and governance-only approvals separately.

## SA
Machine-observable state is ground truth; unsupported self-description receives no credit.

## DI
S_del(T,H)=P(delivered=1 AND verifier_pass=1|T,H).
Also report false completion, held-back invalid, false rejection and F(H,p).

## Instrument validity
Run specification-key consistency tests. Identical cross-tier errors trigger item/key audit.
Use graded scores and separated failure modes where informative. Report headroom/saturation.
