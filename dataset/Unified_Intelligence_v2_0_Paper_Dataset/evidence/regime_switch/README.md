# Same-Seed Regime-Switch Evidence

`frontier.csv` and `haiku.csv` are byte-for-byte copies of the two tracked
measurement tables used by Version 2.0. `paired_results.csv` and
`analysis_results.json` are generated by `tools/analyze.py --write`.

The comparison holds the harness, protocol and seeds fixed while changing the
executor/model. It is therefore a matched executor comparison, not a Harness
Scaling Curve segment.

The frontier model and executor version are not present in the archived source
CSV and remain unknown. Haiku is identified as `claude-haiku-4-5` in the
measurement documentation.
