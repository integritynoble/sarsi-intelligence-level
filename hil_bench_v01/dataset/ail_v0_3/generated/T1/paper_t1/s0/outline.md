# Outline for the Results section

Write `results_section.md` (one or two paragraphs) reporting PSNR on the **KAIST** dataset only,
using `evidence.json`. PSNR: higher is better.

Required elements (disclosed; each is checked):
1. Name the best method on KAIST by the stated direction, and give its PSNR value exactly as in the evidence.
2. Name the second-best method and state the margin between best and second-best, computed as the absolute
   difference and rounded to 2 decimals.
3. Refer to the table by its name (Table 2).
4. Do not state any number that is not in the evidence or is not the margin above.
